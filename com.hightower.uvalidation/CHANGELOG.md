# Changelog

All notable changes to UValidation are documented in this file.

## [0.0.1] - 2026-11-08

### Added

- Serialized field validation attributes for required references, strings, collections, and nested data.
- Inspector validation messages and invalid-object feedback in the Hierarchy and Project windows.
- Recursive validation for serializable classes, structs, collections, managed references, and Unity dictionaries.
- Custom validation through `IValidatable` and a fluent runtime validation API.
- Optional enforcement for scene, prefab, and ScriptableObject saves, Play Mode, Editor quit, and player builds.
- Unity 6.3 compatibility with UI Toolkit Hierarchy integration on Unity 6.6 and newer.
